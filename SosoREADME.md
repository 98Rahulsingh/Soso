# Soso (Shizuku App Manager)

Root (`su`) commands removed; all package toggle, sync, standby, and mode features run via **Shizuku** (`rikka.shizuku.Shizuku`).

## Features
- **Modes:** `Default`, `Gaming`, `Battery`, `Safe Lock` + `Run Mode`
- **Controls:** `Inverse`, `Important`, `All`, `Allow sync`, `No aggressive`, `Unset`, `Disable`, `Enable`, `Move`
- **Failure Report:** Tracks command exit codes and package state verification logs
